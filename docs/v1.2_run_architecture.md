# v1.2 Run Analysis architecture

Public visitors can view the latest validated snapshot. They cannot start
unlimited OpenAI-backed Python runs.

## Authorization

The Next.js route `POST /api/run-analysis` compares a submitted owner secret
with the server-only environment variable `RUN_ANALYSIS_SECRET`.

- The secret is never stored in `localStorage`.
- The secret is never prefixed with `NEXT_PUBLIC_`.
- Unauthorized requests receive `401`.
- If `RUN_ANALYSIS_SECRET` is unset, every request is rejected.

## Trigger

After authorization, the server may call GitHub Actions
`workflow_dispatch` using server-only:

- `GITHUB_TOKEN`
- `GITHUB_REPOSITORY` (`owner/name`)
- optional `GITHUB_WORKFLOW` (default `run-market-analysis.yml`)
- optional `GITHUB_REF` (default `main`)

The Next.js app does not run Python and does not shell out.

If GitHub dispatch variables are missing, the authorized owner receives
`503` with `phase: not_configured`.

## Workflow

`.github/workflows/run-market-analysis.yml` is a concurrency-locked scaffold
(`market-analysis-run`, no overlapping cancel). It does **not** yet execute
or auto-commit a snapshot. That is intentional until visual review and secret
setup are complete.

Intended later command:

```bash
python -m src.main --run-id gha-$GITHUB_RUN_ID --export-web-snapshot
```

## Status

`GET /api/run-status` reports whether dispatch is configured. Live GitHub
Actions polling can be added later without a database.

## Assumptions

- One owner secret is enough for v1.2.
- There is no public signup or user database.
- Snapshot as-of date is not the same as pipeline execution time.
